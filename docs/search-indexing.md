# Search indexing

The public sitemap is https://nicolaslescalier.com/sitemap.xml, generated by
`jekyll-sitemap` and advertised in `robots.txt` for all crawlers.

## Automatic IndexNow notifications

The **Notify search engines** GitHub Actions workflow runs after a successful
**pages build and deployment** on `main`. It can also be run manually on `main`.
It checks the live ownership file, downloads the live sitemap, and validates the
HTML, canonical URL, and indexing directives of each page before submitting.

The first run submits all indexable sitemap pages. Later runs compare page hashes
against the last successful run and notify only new, changed, or removed URLs.
Shared template changes can legitimately affect every page. If GitHub evicts the
cache, the next run submits the current sitemap again. A failed crawl/submission
does not advance state. HTTP 202 means ownership validation is pending and does
not advance state either. The workflow summary lists the submitted URLs.

IndexNow shares notifications with participating engines. It does not guarantee
indexing or ranking, and does not replace the sitemap or Search Console.

The key in `.github/indexnow.json` is a public site-ownership token, not a GitHub
or Bing account credential. Its matching root-level `.txt` file must remain
public. No account API key or repository secret is required.

Validation before publication:

```sh
python3 -m unittest discover -s tests -p 'test_*.py'
python3 scripts/indexnow.py --dry-run
```

## Bing Webmaster Tools

Manage the property at https://www.bing.com/webmasters/ and submit the sitemap
URL above. Ownership may be imported from Google Search Console. Bing's Sitemaps
and URL Inspection screens show processing/indexing results; a successful
submission is distinct from completed crawling and indexing.
